## Current Project — PrizeBee

PrizeBee is a Shopify application that lets merchants run compliant cart-based sweepstakes to increase average order value. Customers opt in from the cart, qualifying paid orders become weighted entries, and a scheduled monthly draw selects a winner.

Under the hood it is a Next.js 15 and TypeScript monorepo deployed on Vercel, backed by Supabase PostgreSQL with Drizzle ORM. It integrates the Shopify Admin GraphQL API, supports dual billing providers (Stripe and Shopify Billing), and processes order and refund webhooks with HMAC signature verification. All personally identifiable information is encrypted at rest with pgcrypto, and the storefront banner ships as a Liquid theme app extension.
